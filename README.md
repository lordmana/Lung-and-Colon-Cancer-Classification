# Lung and Colon Cancer Classification

This project is a lightweight deep learning / image-classification workspace for the LC25000 lung and colon histopathology dataset. It is set up as a Python project using `uv` for dependency and environment management.

## Project purpose

The repository is intended to provide a clean starting point for:

- loading and exploring the dataset,
- preprocessing medical images,
- training a classification model,
- evaluating model performance,
- experimenting with deep learning approaches for binary or multiclass cancer detection.

## Repository layout

- `main.py` — application entry point
- `pyproject.toml` — Python project metadata and dependency definitions
- `data/` — dataset files and image directories
- `notebook/` — Jupyter notebook experiments
- `.venv/` — local virtual environment generated by `uv` (not committed)

## Requirements

- Python 3.9+
- `uv` package manager
- Internet access for downloading dataset dependencies when needed

## Using UV in this project

`uv` is used to manage the Python environment and project dependencies in a fast, modern way.

### 1) Install UV

On macOS with Homebrew:

```bash
brew install uv
```

Or install via the official installer:

```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
```

### 2) Create the environment and install dependencies

From the project root:

```bash
uv sync
```

This command will:

- create a local virtual environment for the project,
- read dependencies from `pyproject.toml`,
- install the required packages into the environment.

If the environment already exists, `uv sync` will update it to match the current dependency definitions.

### 3) Run the project

```bash
uv run python main.py
```

This ensures the command runs inside the project-managed environment without manually activating the virtualenv.

### 4) Activate the environment manually (optional)

```bash
source .venv/bin/activate
```

Then run:

```bash
python main.py
```

### 5) Add a dependency

If you add a new library for the project:

```bash
uv add matplotlib
```

This updates `pyproject.toml` and the lockfile automatically.

### 6) Remove or update dependencies

```bash
uv remove <package-name>
```

or:

```bash
uv add <package-name>
```

### 7) Refresh the environment

If you change dependencies or want to rebuild the environment cleanly:

```bash
uv sync --reinstall
```

## Quick start

```bash
cd /Users/lordmana/projects/Lung-and-Colon-Cancer-Classification
uv sync
uv run python main.py
```

## Notes

- The project is structured to keep dependencies explicit in `pyproject.toml`.
- `uv` is preferred over a plain `venv` workflow because it is faster and keeps dependency management consistent across local development.
- The dataset is stored in the `data/` directory and should be used as the primary source for model training and experiments.
